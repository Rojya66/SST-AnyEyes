# SST CHB V2.1 屏幕联调

联调工具直接连接 ARM 的 Modbus TCP。Windows Python 3.9 及以上带 Tkinter 即可运行。发布时将本目录和仓库内 docs/DPRAM_Screen_V2/DPRAM_MODBUS_POINTS.csv 一起保留。

从工程根目录运行。

    python tools/hmi_v2/panel.py <ARM的IP>
    python tools/hmi_v2/panel.py --probe <ARM的IP>

默认 TCP 502、Unit ID 1、DSP 受理超时 10 s。可用 --port、--unit 和 --timeout 覆盖。运行 GUI 后点击连接，程序先核对 `0500=5353`、`0501=0201` 和 050C/050D 的 DSP 节拍。节拍停更时显示连接状态并禁止新操作。--probe 只做读寄存器核对。

## 四个界面

- **运行与开关**分别显示 CHB/DAB 请求和 PWM、QF1/KT1 目标和实际触点、预充条件、总耗时、连续达标时间及三相电气量。读过活动参数后，预充页同时显示实际超时与连续达标定值。操作员点击按钮才发送控制。回执显示 DSP 已受理或拒绝，实际动作看 PWM 与触点。
- **模块诊断**按相显示物理 UNIT1–14。三个观察掩码用十进制或 0x 十六进制输入。观察只改变采集目标。点“观察全部投入”会把各相生效运行 PM 复制到观察掩码。程序仅在该页读取所选相 56 字，按有效位呈现 Udc、Ir、Ig、PT100；同时呈现 501 当前掉线、跳闸失联和 701 首锁存位置。
- **遥调**先读取活动值，再按名称、地址或符号筛选，双击编辑。CHB 模式 023B、自动/手动 023C 和风扇均压阈值 023D/023E 都在此页设置。应用提交整组 63 字，成功或失败都读取 DSP 的实值。风扇区显示本次事务的阈值与代号，以及各相 UNIT 已确认、拒绝和当前投入 PM 中未确认的位置。若 UNIT 尚未得电，闭环预充时会重新下发并确认。保存和加载沿用 EEPROM 服务。
- **故障与历史**显示五位报码、501 跳闸位置、701 首锁存位置和最近 32 条 DSP 记录。触摸屏联调工具运行且保持连接时会自动把读到的故障追加到 %LOCALAPPDATA%\SST_CHB\fault_history.csv。可用 --journal 指定路径。日志记录本机收到时刻、连接会话与 DSP 序号；每次连接或检测到 DSP 上电计时回退都开启新会话。一个历史环可能在重连时再次归档，按会话与序号辨认。离线期间超过 DSP 容量的旧条目无法从屏幕补读。

## 接入

只用 FC03/06/10。先写控制块或遥调块，再单写左邮箱 1FFE。0x0504/0x0507 的 DSP 完成计数与操作号联合确认；等回执期间操作按钮禁用。超时后标明动作未确认，继续查看运行和触点；核对设备后手动重连。提交不会因网络超时自动重发。只操作一个写客户端。综合、模块和历史分别核对 0502、0503、0800 的奇偶发布戳，读期间戳变化时重新取样。

现场触摸屏移植可沿用同样的点表、批量写、邮箱和回执步骤。当前 Windows 工具独立于既有 sstMaster 和现场触摸屏组态工程。现场 ARM 及实际屏幕组态、网络时延和柜内动作需在台架核对。

## 本地验收

    python tools/hmi_v2/test_protocol.py

测试使用本机回环上的模拟 ARM 服务器，覆盖签名、Modbus 请求、左右字序、邮箱提交、控制回执计数回绕、遥调拒绝回显与保存等待、模块采样、32 条历史跨包及本地归档。
