# 板级调试与 10 kHz 验收

## 1. 配置和静态核对

记录固件 build_result.json、宏组合、模块位图、FPGA版本和板卡编号。核对 C6748.cmd 的 CS2/CS5 寄存器位置、GPIO69 TAD、GPIO142 FAULT、GPIO101 DPRAM、GPIO104 RS485、GPIO40 WDI，以及 ADC 极性、增益和继电器输出。

首次台架检查显式设 `SST_SIMULATOR_MODE=1`；2026-10-14单UNIT调试源码默认是 `SST_SIMULATOR_MODE=1,SST_ENABLE_DPRAM=0`，临时输入宏`SST_BENCH_INPUT_SIM`默认关闭。使用真实主回路必须保持测试宏为0，并按实际需要恢复远控/DPRAM配置。无主回路输入测试单独见[BENCH_CLOSED_LOOP_DEBUG.md](BENCH_CLOSED_LOOP_DEBUG.md)。上电 run/dab 应均为0。确认原20秒初始化等待和WDI。确认控制周期实际为100us，并与 sample_period_s=0.0001 一致。

## 2. 10 kHz 实时性测量

示波器/逻辑分析仪同时观察：FPGA 外部 TAD 脉冲、DSP GPIO43（或GPIO45）和实际PWM/故障封波信号。

| 测量 | 定义 | 验收 |
|---|---|---|
| TAD 周期 | 相邻 GPIO69 上升沿 | 100us，与FPGA设定相符 |
| 中断入口延迟 | GPIO69上升沿 → GPIO43上升沿 | 记录最大值及抖动 |
| 控制执行宽度 | GPIO43高电平 | 记录最大值，和源固件对比 |
| 总完成时间 | 入口延迟 + 完整ISR时间 | 必须小于100us并有实测余量；补测入口/出口未被GPIO高电平覆盖的部分 |
| 丢触发 | TAD个数与控制脉冲个数 | 无漏拍、无合并触发 |

分别在停机、CHB开环、DAB爬升、PLL、闭环、最大通道波形、参数查询洪泛、畸形帧、DPRAM遥测、Timer2故障锁存处理和硬件故障状态测量。使用参考源固件作同条件基线，记录CPU/FPGA时钟。TI原ISR不保证自动嵌套抢占，低优先级ISR阻塞也计入入口延迟。

GPIO43/45的高电平只覆盖控制主体，未包含全部ISR序言、初始bank操作和低电平后的尾部。不能直接把入口延迟加高电平宽度当作完整完成时间；应结合循环计数或额外板级采样确定完整预算。只有这些实测通过后，才能确认硬件上的10kHz时限；构建通过和算法回归不能替代此项。

## 3. 通信

AnyEyes使用参考工程同一串口协议设置，按 ANYEYES_MAPPING.md 配置功能码、波形和面板。测试握手、心跳、断线重连、F0读、F1写、F2/F3波形、F4/F5状态。检查负电流/相角缩放、饱和数值、非法索引/长度和CRC恢复。

切换VOFA宏后检查4通道顺序 Ua、Udc相平均、Port_State、PLL角度。115200 8N1下4通道帧20字节，理论上限576帧/s；后台默认50Hz。485不接受A5 5A维护帧，切VOFA时确认同一UART只有JustFloat输出，并口维护仍可独立运行。

仿真器模式确认远程启动被拒绝，直接调试器修改可运行。非仿真器DPRAM开启时确认DPRAM控制生效，串口启动不与其争用。串口紧急停机只能停机。

按 [DPRAM_EXTENSION.md](DPRAM_EXTENSION.md) 检查请求 `0x66002C00`、回复 `0x66002D00`、遥测 `0x66002E00`、历史 `0x66002F00`：逐项读回54点，覆盖启停、CHB/DAB独立封波、复位、开闭环、PI、快速保护、原保护及两套预充阈值。核对序号回带、CRC错误/范围错误、重复请求幂等、停机及保存忙互锁、回复完整后邮箱21通知和快照偶数版本一致性。测试请求洪泛与连续遥测/历史发布时的100µs时序；主机等待回复后再提交下一笔。

## 4. 功率控制

依次完成无功率板级检查、低压CHB开环、独立DAB原边爬升、预充/旁路/PLL、闭环兼容启动、Id斜坡启动。每一步核对相位、极性、调制限幅、DAB实际占空比、断路器脉冲和旁路保持输出。

## 5. 故障和持久化

按 FAULT_CODES.md 逐项可实施故障注入：硬件FO/FB、模块、软件OC/OV、预充/PLL超时。核对即时封波、主状态、首故障、等级、当前清单、历史重触发和停止后的复位。

EEPROM保存仅停机执行，测试显式SAVE、读回、掉电加载、CRC损坏拒绝、未知版本拒绝、运行中拒绝保存，以及不存在EEPROM时返回错误。页6/7为v2的108字节/50字镜像，实测v1的92字节/42字兼容恢复；临时保护总使能及run/dab/复位不能随镜像恢复。旧V/Q遥调不能再自动写Page1。记录区域占用，核对旧设备是否已有日志使用该区域。
