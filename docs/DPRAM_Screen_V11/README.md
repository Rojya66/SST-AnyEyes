## 2. 地址与字节序

全部表格的Modbus地址都是**0起始的16位寄存器偏移**，不是DSP字节地址。

```text
ARM字节地址 = 0x60000000 + 2 * Modbus寄存器地址
DSP字节地址 = 0x66000000 + 2 * Modbus寄存器地址
40001显示编号 = 40001 + Modbus寄存器地址(十进制)
```

例：`0x0207`=十进制519=显示编号40520；ARM `0x6000040E`；DSP `0x6600040E`。

Modbus网络每字高字节在前；ARM/DSP本地均小端。屏幕“交换高低字节”应关闭。补充float32采用**低16位寄存器在前**，每个寄存器内部仍按Modbus高字节先传，不要混淆字序和字节序。

完整2400行点表：[DPRAM_MODBUS_POINTS.csv](DPRAM_MODBUS_POINTS.csv)。包含Modbus十六/十进制地址、40001编号、ARM地址、DSP地址、读写权限、类型、比例、范围、生产函数及源码行号；插件128字逐字列出。

## 3. 遥控受理与开关

每笔先构造**全零16字**，只设置本笔动作和可选 `PORT_NAME=1`，最后写邮箱。旧动作字没有“保持启动”语义，DSP只在收到本笔通知时消费。不要重复发送上一笔残留动作。

|动作|Modbus地址|位/值|实际对象|
|---|---|---|---|
|启动|00F2|bit0=1|run_enable=1、dab_enable=1；状态机决定实际发波|
|停止|00F3|bit0=1|两请求清0；STOP优先|
|恒压主模式|00F4|bit0=1|确认当前恒直流电压能力；不改变开/闭环选择|
|DAB解锁/闭锁|00F8 / 00F9|bit0|dab_enable，实际PWM读run_flags|
|CHB解锁/闭锁|00F8 / 00F9|bit1|run_enable；闭环仍走预充/PLL流程|
|故障复位|00FA|bit0=1|完全停机后fault_reset，活动故障不能强制清掉|
|合闸许可|00FB|1允许、2禁止|维护许可；默认0；同写3拒绝|
|手动旁路合/分|00F6 / 00F7|bit0|核心维护接口中的预充旁路输出|
|手动进线合/分|00F6 / 00F7|bit1|核心维护接口中的进线脉冲输出|

手动开关要求：完全停机；手动方式；合闸还要求许可、无故障；旁路合闸前进线命令已合；`SST_ENABLE_SWITCH_OUTPUT=1`。输出宏0时返回5，不伪报实际硬件动作成功。运行中的开关动作由预充/停机状态机管理，维护请求返回忙。进线分闸同时撤销旁路；重复合闸不重触发线圈脉冲。外部断路器1/2没有本机驱动对象，返回7。

自动启动使用原进线/旁路流程，不使用外部断路器许可代替本机预充条件。Word `COM_SYS_MODE` 的运行/测试、自动/手动是管理方式；`ac_mode`单独在补充参数37中设置，0开环、1闭环。不能把Word的PQ直接映射成闭环。

受理结果：`1984`控制计数、`1985`结果；计数前后变化才表示本笔已消费。结果0只表示请求受理，不等于状态已经RUNNING；读 `0500`、`1989`、`198F`及故障区确认实际进程。

## 4. 遥调、负PI和精度

修改旧块2前读取43字实际值作为底稿，只改目标字段，再写完整块和邮箱2。原块2不再周期性回写，防止覆盖屏幕编辑中的值；上电以及处理完邮箱2后才返回实际值。若刚通过AnyEyes/补充区/仿真器修改过配置，优先用补充实际参数区核实，再重新建立旧块底稿。

|旧Modbus点|真实对象|编码|
|---|---|---|
|0207|dc_voltage_ref_v，单模块目标|1 V/count，正int16；保持未改项的小数精度|
|0208|开环频率/闭环PLL额定频率|Hz×10；并网模式不能强迫电网频率|
|021A|voltage_kp|signed int16，Kp×100000|
|021B|voltage_ki|signed int16，Ki×100|
|021C|current_kp|signed int16，Kp×1000|
|021D|current_ki|signed int16，Ki×1000|
|0200..0204|AD、FO、FB使能|按Word掩码，调用真实FPGA写接口|

**负PI处理方案**：先把16位字解释为 `int16_t`，再除以缩放；结果直接写入现有 `g_chb_dab_params.current_kp/current_ki`。d轴、q轴共用这两个带符号增益，Ki仍是连续积分增益，由PI执行时乘采样周期Ts。**不取绝对值、不额外反号、不把Ki改成Ki×Ts后再次积分。**`current_feedback_sign`是独立的采样方向参数，不能为补偿负PI随意反转。

例：Kp=-1.249 → raw=-1249 → 16位`0xFB1F`；Ki=-16.667 → raw=-16667 → 16位二补码。更便于联调的精确值：Kp=-1.250写`0xFB1E`，Ki=-16.000写`0xC180`。屏幕控件必须支持有符号显示；若界面只能发送uint16，输入对应65536+raw，但必须在显示层按int16解码。

|PI|最小值|最大值|分辨率|
|---|---|---|---|
|电压Kp|-0.32768|0.32767|0.00001|
|电压Ki|-327.68|327.67|0.01|
|电流Kp/Ki|-32.768|32.767|0.001|

Word没有冻结这些PI的比例，本版采用唯一参数表的精度。旧注释代码中“全部除100得到PLL/Volt等Factor”**不属于本版直接PI定义**。若现有屏幕统一设了2位小数，需把这四个控件的比例分别改为5/2/3/3位；否则只能地址相同，数值仍不兼容。

整组先校验，失败不部分修改。成功只写变化项：只改Udc不会把原Kp=-1.249166667自动量化为-1.249。主动改PI、保存/加载的16位持久化精度按表执行。旧块2结果在 `1986`计数、`1987`结果；邮箱20和Modbus06/10应答都不能单独当作“设置成功”。

57项完整参数、比例及范围见 [PARAMETERS.md](PARAMETERS.md)。其中包括运行限流、启动Id、PLL、软启动、DAB、快速OC/OV及原软件保护、预充巡检阈值。原组2/组3PI没有独立调节器对象，非零更改返回7，不解释为B/C相PI。

## 5. 普通寄存器维护事务

|寄存器|权限|含义|
|---|---|---|
|1B00|RW|请求序号；非零，每笔新操作换新号|
|1B01|W最后写|1 APPLY，2 SAVE，3 LOAD，4 REFRESH；受理后DSP清0|
|1B02|R|完成序号ACK，完成时最后写入|
|1B03|R|执行结果|
|1B04|R|busy=1等待EEPROM完成|
|1B05|R|出错参数号/旧块字号；FFFF未细分|
|1B06|R|最近完成操作号|

推荐操作：等op=0、busy=0 → 新序号+REFRESH → 等本笔ACK → 改待应用区 → 新序号+APPLY → 等ACK及result=0 → 读实际区 → 如需持久化，再新序号+SAVE。写APPLY后至ACK期间不得继续修改候选区。不要一次Modbus写中把op提前写下、后面还修改参数。

同一序号+同一操作的重发仅返回缓存，不重复执行。**缓存只识别序号/操作，不比较载荷；修改内容必须换新序号。**同号不同操作或序号0返回8；本机重启后事务缓存清空。SAVE进行时不接收下一笔普通事务；主机必须等待，不能改写尚未完成的op/候选值。

SAVE保存**当前活动值**，不隐含APPLY。LOAD整体校验EEPROM后恢复活动值，不自动覆盖屏幕候选区；继续编辑前发REFRESH。保存约2.2秒，最终ACK才表示写入和逐字节校验结束；故障/通信仍由后台运行。

持久化沿用v2页6/7镜像：现代42字+原保护8字。快速保护开关、系统管理方式、AD/FO/FB屏蔽属于运行期配置，不写入该镜像，避免把调试屏蔽状态持久化。自动加载宏保持0；上电是否LOAD由现场明确决定。

结果：0成功；1地址；2只读；3范围/组合；4忙或未完全停机；5权限/联锁拒绝；6EEPROM；7功能不支持；8事务冲突。部分组合错误只给FFFF；以结果和实际区核实，不能拿输入缓存作依据。

## 6. 遥测、状态和故障

`PORT_STATUS 0501`：bit0内部旁路触点；1/2内部进线合/分；3/4外部断路器合/分；5接地；6隔离；7模块H桥闭锁；8 CHB闭锁；9 DAB闭锁；10外部合闸许可；13..14系统方式；11/12/15保留。

本机未接入的外部断路器、接地及隔离反馈位固定0；实际进线/旁路触点只有反馈宏1时有效。**宏0时合/分都为0代表未知，不能显示成“已分闸”。**`1990`是进线/旁路命令，`1992`才是反馈；先检查 `198E.bit2`。

`PORT_RUN_STATUS 0500`低6位：07停止、02预充、03预充完成/旁路延时、05就绪待PLL、20正常运行、08故障；bit7来自外部带电判定。核心原0..5状态另在1989，不能与Word枚举混用。

量测：P为kW×10；Q为kvar×10；V为V；I为A×10；PF×100。单相V_A为AN RMS，B/C无效0；三相V_A/B/C保留原生产者的线电压RMS语义。`0512 DC_V`固定为**A相串联总母线电压**；补充`1994/1995`为活动相模块均压float32，单相即A相均压。二次侧电压/电流、中线、谐波及下垂没有有效生产者的字段固定0。

补充 `19A1/19A2`为旧块3各字段有效位图，`19A4`为插件配置有效位图。插件位图只表示配置了生产者，不是逐插件通信健康位；U7/U11/U15、U17和未配置B/C不发布有效镜像。插件数据沿用原始FPGA编码，不当成已经标定的V/A。原块3约60ms，默认4个有效插件时每插件约240ms；邮箱无ACK队列，主机应周期读固定区。

旧故障0502：bit0接触器、1断路器、2风机、3控制器、4辅助电源、5EPO、6模块、7逆变器、8相序、9频率、10过流、11欠压、12过压、13通信、14同步、15总故障。内部旧bit13软件OV重映射到外部bit12；内部旧bit14软件OC重映射到外部bit10。预充/非法配置等没有合适旧分类的原因只置总故障并保留详细码。

详细故障：`19C0`Word故障、`19C1`内部Port原字、`19C2`FaultType原字、`19C3`核心原因、`19C4`当前首码、`19C5`等级、`19C6`当前数、`19C7`历史数、`19C8..19E7`32个当前详细码、`19E8/19E9`原软件OC/OV锁存。等级0/1/2/3对应参考一/二/三/四级，4无故障。当前首码是当前列表首项，**不是不可变首触发锁存**；原详细历史仍在旧纯并口区。

补充快照读取：先读1980，必须偶数；读取需要的状态/故障/实际参数；再读1980，必须相同偶数，否则重读。此版本戳保证DSP后台发布一致性，不保证不同TAD生产的标量同一瞬间；对实时波形继续使用VOFA/AnyEyes。

## 7. 控制、构建和10kHz边界

新工程默认DPRAM=1、仿真器=0、输入注入=0；保留现场单相、VOFA 460800和1ms通信设置。开关输出/反馈宏仍0。改仿真器模式后远控返回5；关闭DPRAM后新模块不访问并口。

**现场参数原样继承，并没有改成60V参考配置**：当前命令初值133V/模块、预充25V、运行限幅120A峰值、快速OC 120A/5拍、快速OV 300V、原RMS OC 120/140A、原OV 300V、外环Kp/Ki 0.1/3，电流Kp/Ki约-1.249166667/-16.66666667。命名含100V的宏并不代表这些现场值已经恢复为100V试验推荐值；本次没有替用户重整定控制器。

ISR、采样、保护配置与766fad0逐字节一致；原控制文件68个既有实体的有效代码哈希一致，只追加后台维护开关入口。协议解析、参数校验、EEPROM和遥测打包均在主循环；补充发布每轮最多16字。未把通信处理塞入10kHz FPGA ISR。

编译与主机测试不能证明100us实际裕量：需按 [DEBUG_STEPS.md](DEBUG_STEPS.md) 用GPIO测最坏占用/抖动和后台响应；并口访问仍可能带来EMIFA争用。继承现场基线的部分历史断言失败见修改记录，不能据本次通信编译通过认定主回路控制已重新验收。

## 8. 能力边界

|文档能力|本版处理|
|---|---|
|CHB/DAB启停、单桥、停机复位|原地址接入当前核心|
|单模块Udc、频率、组1真实PI、硬件保护使能|原块2实际生效及回读|
|限幅、PLL、预充、原/快速保护、启动/DAB参数|新增普通Modbus逐参数寄存器|
|保存/加载、详细故障、真实核心状态|新增普通Modbus事务/只读区|
|PQ、下垂、谐波/STATCOM附加调节器、组2/组3独立PI|未实现，更改返回7|
|其他电气端口、外部断路器、传感器接线动态配置|未实现，不能误路由到HVAC|
|正常停机降功率软停|当前核心仍为撤销请求封波；本次不新增软停算法|

因此本版完成的是**当前已有控制能力的DSP侧兼容与缺项补点**。完整Word还包含超出当前控制器能力的算法；这些不能仅靠通信映射自动成立。屏幕原控件的PI比例、Mailbox最后写流程及新增点位需按本文联调。
